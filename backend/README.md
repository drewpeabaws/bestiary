# Bestiary backend (FastAPI)


## Development setup (backend)

### Prerequisites
- Python >=3.12
- `uv` (Astral's Python package manager: https://docs.astral.sh/uv/)
- `make`

### Quick start
```bash
cd backend
make setup            # Install deps + copy .env.example to .env
# (Fill in .env values — at minimum JWT_SECRET_KEY)
make dev              # Run FastAPI dev server on localhost:8000
make test             # Run pytest
make lint             # Ruff check + format
```

### Env vars
See `backend/.env.example` for required vars. Copy to `backend/.env` (gitignored) and fill in values.

### Make targets
Run `cd backend && make help` to see all available targets.
